# 길위의 프랑크푸르트

프랑크푸르트 시내 대중교통 경로를 비교하는 정적 웹사이트입니다. 원본 코드는 `src/`에 있습니다.

## 프로젝트 구조

```text
src/
├─ index.html      # 화면 구조
├─ css/style.css   # 스타일
└─ js/script.js    # 경로 검색과 지도 동작
start-local.cmd    # Windows 로컬 실행
```

## 로컬 실행

Windows에서는 `start-local.cmd`를 더블클릭하고 `http://127.0.0.1:8765/`을 여세요. 창을 닫으면 서버가 종료됩니다.

직접 실행하려면 이 디렉터리에서 다음 명령을 실행하세요.

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory src
```

출발지와 도착지는 화면의 정류장 후보에서 선택합니다. 검색은 Transitous MOTIS v6의 실제 경로 API를 호출합니다. 지도는 OpenStreetMap 타일을 사용하며, Leaflet은 CDN에서 불러옵니다. 따라서 인터넷 연결이 필요합니다.

## 현재 한계

- 정류장 후보는 프랑크푸르트 주요 지점의 고정 목록입니다. 입력한 임의 주소 검색은 지원하지 않습니다.
- 배차 간격과 요금은 근거 데이터가 없어 표시하지 않습니다.
- 외부 API 응답과 실제 브라우저 화면은 현재 작업 환경의 DNS 제한으로 검증하지 못했습니다.
- Transitous는 비상업적 오픈소스 앱을 위한 서비스입니다. 이번 구현은 개인 프로토타입으로 취급하고, 공개 운영 전에 [이용 정책](https://transitous.org/api/)에 맞게 소스 공개와 연락처를 준비해야 합니다.
